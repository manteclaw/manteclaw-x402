How paying per call works

x402 revives the HTTP 402 “Payment Required” status code. There is nothing to sign up for — the payment is the API key, and it settles on Solana for each individual call.

1

Request. Call any endpoint with a normal GET request, like any REST API.

2

402 reply. The service answers HTTP 402 with the exact price for that call — never more than $0.02.

3

Sign. Your x402 client signs a USDC payment on Solana. The facilitator covers the network fee — no SOL needed for gas.

4

Data. Retry the same request with the payment attached and the JSON comes straight back.

// Any x402 client with a Solana (SVM) signer does this automatically:
// it sees the 402, signs the USDC payment, retries, returns the data.
const res = await fetchWithPayment(
  "https://manteclaw-x402-solana.fly.dev/chain/slot"
);
const data = await res.json();
// { "slot": 391204455, "block_height": …, "network": "solana" }

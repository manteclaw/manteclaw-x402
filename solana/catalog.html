How paying per call works

x402 revives the HTTP 402 “Payment Required” status code. There is nothing to sign up for — the payment is the API key, and it settles on Base for each individual call.

1

Request. Call any endpoint with a normal GET request, like any REST API.

2

402 reply. The service answers HTTP 402 with the exact price for that call — never more than $0.02.

3

Sign. Your x402 client signs a USDC payment on Solana. The facilitator covers the network fee — no SOL needed for gas.

4

Data. Retry the same request with the payment attached and the JSON comes straight back.

// npm i x402-fetch viem — then this is the whole integration
import { createWalletClient, http } from "viem";
import { privateKeyToAccount } from "viem/accounts";
import { base } from "viem/chains";
import { wrapFetchWithPayment } from "x402-fetch";

const account = privateKeyToAccount("0xYOUR_PRIVATE_KEY");
const wallet = createWalletClient({ account, chain: base, transport: http() });
const fetchWithPayment = wrapFetchWithPayment(fetch, wallet);

// The 402 handshake, signing and retry all happen inside this call
const res = await fetchWithPayment(
  "https://manteclaw-x402-solana.fly.dev/defi/gas-tracker"
);
console.log(await res.json());
# Without a payment, every paid endpoint answers 402 with its price

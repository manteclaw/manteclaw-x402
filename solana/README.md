# Manteclaw x402 service — Solana-native edition

199 paid Solana-data endpoints + free `/health`, settled in USDC on
Solana mainnet via x402 (exact SVM scheme, PayAI facilitator).
Live origin: `https://manteclaw-x402-solana.fly.dev` (Fly app
`manteclaw-x402-solana`, iad, shared-cpu-1x, 256MB, always-on).

**History:** v1 (2026-11-22) cloned the Base service's endpoint set and
served Base/EVM data with Solana settlement. Alex directed on
2026-11-23 that the Solana APIs be Solana-focused, so v2 rebuilt the
endpoint set Solana-native: the payment wiring is unchanged, the data
is all Solana now. The Base service (`~/workspace/x402-service/`) is a
separate service and is untouched by this build.

Verified SDK facts (from v1, still true): x402 2.9.0 ships the SVM
exact server scheme; its built-in USDC for the Solana mainnet network
id is exactly the mint above; `parse_price("$0.01")` → `10000`.
`requirements.txt` pins `solana==0.39.0` — the `x402[svm]` extra's
fresh resolve picks solana 0.42.0, which removed `solana.rpc.api` and
breaks the SVM import.

Implementation notes that matter:

- Route patterns for the payment middleware must use the SDK's
  `[param]` syntax, not FastAPI's `{param}` — braces are escaped
  literally by the SDK's pattern compiler and parametrized endpoints
  would serve unpaid. `server-solana.py` converts patterns at wiring
  time (see `_pattern`).
- The middleware syncs the facilitator's supported-kinds lazily on
  the first paid request; a startup hook pre-warms `server.initialize()`
  with retries so the first caller doesn't eat that timeout.
- Dexscreener pair lists are filtered to pairs where the token is the
  BASE asset (the quote-side bug found on the Base service).
- Pyth's Hermes price-update endpoints now require an API key (401),
  so the oracle family serves the real Pyth feed directory and
  cross-checks prices across Jupiter / Dexscreener / CoinGecko instead
  of pretending to serve Pyth prices.
- `getStakeActivation` was removed from Solana RPC; stake activation
  is computed from the stake account's delegation epochs.

## Files

- `server-solana.py` — the whole service (FastAPI + handlers + wiring).
- `catalog.html` — public catalog page, generated by `build-catalog.py`
  from the server REGISTRY. Verify with `catalog-price-check.py` and
  `catalog-filter-check.py` (both must pass).
- `.well-known/` — static discovery files, regenerated by
  `build-discovery.py` from the server's own document builders (the
  server also serves the same documents dynamically).
- `test-solana.py` — local verification: HTTP checks (health, catalog,
  discovery, 402 terms) against a running server on :8402, plus a
  direct-call sweep of all 199 handlers. Run:
  `.venv/bin/python test-solana.py`
- `requirements.txt` — see the `solana==0.39.0` pin note above.

## Deploy

Via GitHub Actions in the manteclaw-x402 repo (`solana/` path,
workflow `deploy-x402-solana.yml`) — direct Fly deploys from this VM
fail at the Depot builder. No Fly secrets are required: payTo and
facilitator defaults are in code, overridable via
`SOLANA_WALLET_ADDRESS` / `FACILITATOR_URL` / `SOLANA_RPC_URL` /
`PORT` (see `.env.example`).
